# Cryptora Cloud

Cryptora Cloud is a secure file storage application built with
Python, Streamlit, Fernet encryption, and Amazon S3.

## Features
- File encryption using Fernet
- Block-based file processing
- Encrypted package upload to Amazon S3
- Encrypted file download
- File decryption and restoration
- SHA-256 integrity verification

## Technologies
- Python
- Streamlit
- Cryptography
- Boto3
- Amazon S3
- AWS App Runner

## Security
Encryption keys and AWS credentials must be configured
securely and must never be committed to GitHub.
